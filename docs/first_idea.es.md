Iventory + AI:
- Context: El mundo de los software basados en inventorios esta tremendamente saturado por infinidades de soluciones, nostros queremos automatizar los procesos manuales de estos inventorios usando inteligencia artificial, queremos que el ingreso que productos, la salida, facturas, pagos, reportes, recordatorio de pagos y todo el maganment del manejo de inventorios sea automaizado.
- Scope: para este primer MVP queremos crear un modulo de creación de productos, estos productos van a tener relaciones con categorias, por lo que debemos crear un modulo de categorias para crear estas categorias y al momento de crear el producto estas categorias serán mostradas para crear el producto, llamando a categorias como Country, State, City, y demás que hagan parte de describir el producto, este modulo también permitirá crear templates para crear futuros productos. Deberá existir otro modulo de se llama AI donde habrá un chat con la AI, donde el usuario podrá crear porductos, eliminar productos, actualizar productos, sean uno o muchos, los medios para pasar la información serán, texto, audios, fotos, archivos XML, JSON, excel, la AI deberá crear estos productos leyendo la información del usuario y generando preguntas necesarias para la creación de estos productos, entonces la AI deberá entender que quiere hacer el usuario para conectarse a las APIś creadas y al final la AI le dará un reporte un resumen de la operación detallando los que creó, modifcó o elimino, todo esto bajo el contexto de creación de productos, eliminación o actualización.
  - Diseño: no tenemos colores definidos aun, por lo que se podrán usar colores estrategicos, en cuanto al UI, algo con border algo redondos y siendo muy limpios en el UX, no queremos saturar los procesos, si no que sean cortos pero que no afecten los requerimientos acotados en el scope.
